SpaceHop 1.10.1

Для Mac с Apple Silicon (arm64), macOS 13–15.
Работа проверена на macOS 15.7.4. macOS новее 15 пока не поддерживается.

Установка:
1. Открой DMG и перетащи SpaceHop.app на ярлык Applications («Программы»).
   Если используешь ZIP, распакуй его и перенеси SpaceHop.app в «Программы».
2. Извлеки образ диска и запусти SpaceHop из «Программ».
3. Если macOS блокирует запуск из-за неизвестного разработчика,
   открой «Системные настройки → Конфиденциальность и безопасность»,
   найди сообщение о SpaceHop и выбери «Всё равно открыть / Open Anyway».
   Одобряй только эту копию, скачанную из репозитория fev0ks/macos-toolbox.
4. В том же разделе включи SpaceHop в «Универсальном доступе».
5. Для превью окон разреши «Запись экрана». Если macOS предложит
   перезапуск приложения, согласись.

Это локально подписанная ad-hoc сборка без Developer ID и нотарификации.
Отключать Gatekeeper, SIP или защиту macOS не требуется.

Ctrl + ←/→: мгновенное переключение Spaces.
Удерживать окно мышью + Ctrl + ←/→: штатный перенос окна через macOS.
Ctrl + ↑: обзор окон текущего рабочего стола.
Ctrl + ↓: обзор окон текущего приложения.
Esc или клик по фону: вернуться к исходному окну.
Горизонтальный системный свайп: мгновенное переключение Spaces.
Чувствительность жеста: настройки через значок SpaceHop в строке меню.

Превью хранятся только в памяти. Передачи данных в интернет нет.
Дополнительный доступ к Documents или полный доступ к диску не нужны.

Исходники, ограничения, лицензии и подробная инструкция:
https://github.com/fev0ks/macos-toolbox/tree/main/space_hop
