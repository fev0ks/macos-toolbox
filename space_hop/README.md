# SpaceHop

Небольшая утилита для мгновенного переключения macOS Spaces и обзора окон с одинаковыми карточками. Текущая версия исходников — **1.10.1**. Интерфейс приложения на русском языке.

## Возможности

- Мгновенные переходы через **Ctrl + ←/→** и горизонтальный системный жест трекпада.
- **Ctrl + ↑** — окна текущего Space; **Ctrl + ↓** — окна активного приложения на текущем Space. Вертикальные системные свайпы открывают соответствующий обзор.
- Одинаковые карточки с превью, названием приложения, проектом и открытым файлом/разделом; вторая строка приглушена. Порядок: приложение, затем заголовок окна, с естественным порядком чисел. Для JetBrains IDE название проекта имеет приоритет над текущим файлом.
- Центрирование рядов, отступы от меню и Dock, навигация стрелками по реальному расположению карточек.
- Зелёная рамка исходного активного окна; жёлтая рамка выбора мышью или клавиатурой. Движение стрелками убирает подсветку под неподвижным курсором до следующего движения мыши.
- Кнопки **⏻ − ×**: завершить приложение обычным запросом, свернуть/развернуть конкретное окно, закрыть конкретное окно. Диалоги сохранения остаются под управлением приложения.
- Свёрнутые окна включены в обзор; их кнопка «−» жёлтая. Клик по карточке разворачивает окно и фокусирует его.
- Маленькие карточки окон других Spaces этого же дисплея внизу. Клик переключает Space и фокусирует выбранное окно. В обзоре приложения нижняя полоска также ограничена этим приложением.
- Автоматический размер карточек с учётом масштаба экрана; ручной размер сохраняется отдельно для каждого монитора. **«Авто»** сбрасывает настройку текущего экрана. Прозрачность фона настраивается общим ползунком.
- Пауза, включение обзора свайпами и запуск при входе через значок в строке меню. Автозапуск по умолчанию выключен.

## Совместимость

| Условие | Статус |
| --- | --- |
| Архитектура | Сборка для Apple Silicon (`arm64`); Intel не проверен и этим скриптом не собирается. |
| macOS 15.7.4 | Проверена на реальном Mac; основные сценарии подтверждены пользователем. |
| macOS 13–14 и другие версии 15 | Разрешены проверкой версии, отдельная нативная проверка не проводилась. |
| macOS новее 15 | Мгновенное переключение блокируется проверкой версии. Требуется адаптация недокументированного механизма. |

Полноэкранные Spaces присутствуют в системном списке; их сочетания с несколькими мониторами требуют отдельной проверки. Переключение направляется на дисплей под курсором.

## Сборка и установка

Нужны Apple Command Line Tools со Swift. Если они отсутствуют, установи их через `xcode-select --install`. Внешних библиотек и менеджеров пакетов нет.

Из корня репозитория:

```sh
cd space_hop
./build.sh
```

Скрипт компилирует исходники в режиме Swift 5 с целью `arm64-apple-macosx13.0`, создаёт `SpaceHop.app`, копирует лицензии и подписывает его локальной ad-hoc подписью. В конце запускаются встроенные проверки. Сборка не заменяет уже установленное приложение.

Закрой прежнюю копию SpaceHop, скопируй собранный `SpaceHop.app` в `/Applications` через Finder и запусти оттуда. Одновременно должна работать одна копия утилиты. Эта сборка не имеет Developer ID подписи и не нотарифицирована Apple; если macOS блокирует запуск, используй штатное одобрение конкретного приложения в «Конфиденциальность и безопасность», сохраняя системную защиту включённой.

## Разрешения

1. В **Системные настройки → Конфиденциальность и безопасность → Универсальный доступ** добавь и включи `/Applications/SpaceHop.app`. Это нужно для перехвата событий и управления окнами.
2. Для превью разреши SpaceHop в **«Запись экрана»** (название раздела зависит от версии macOS). Если система предложит перезапуск приложения, согласись.
3. В меню SpaceHop должен появиться рабочий статус. Без разрешения на превью доступны названия и иконки.

Доступ к Documents и полный доступ к диску для превью не нужны. «Уменьшение движения» менять не требуется. Приложение не меняет системные сочетания клавиш, Dock или SIP.

### После пересборки

У ad-hoc сборки меняется подпись. macOS может оставить SpaceHop включённым в списке, но отклонять новую копию. Сначала заново добавь установленное приложение в нужный список и перезапусти его.

Если это не помогло, можно сбросить разрешения **только SpaceHop**, после чего выдать их вручную новой версии:

```sh
tccutil reset Accessibility local.spacehop.app
tccutil reset ScreenCapture local.spacehop.app
```

Эти команды отзывают разрешения; они не выдаются автоматически. Сбрасывать разрешения остальных приложений не нужно. Диагностика из терминала может видеть права терминала/хоста, поэтому статус запущенного `.app` важнее результатов отдельного CLI-процесса.

## Управление

| Действие | Управление |
| --- | --- |
| Предыдущий/следующий Space | Ctrl + ←/→ или горизонтальный системный свайп. |
| Перенос удерживаемого окна в другой Space | Зажать окно левой кнопкой и нажать Ctrl + ←/→. Сочетание целиком передаётся macOS; этот перенос использует её штатное поведение. |
| Обзор текущего Space | Ctrl + ↑ или системный свайп вверх. |
| Обзор окон приложения | Ctrl + ↓ или системный свайп вниз из окна. |
| Выбор карточки | Стрелки, Tab или мышь. |
| Открыть выбранное окно | Enter или клик по карточке. |
| Вернуться к исходному окну | Esc или клик по свободному фону. |
| Перейти к окну другого Space | Клик по маленькой карточке в нижней полоске. |
| Чувствительность/направление горизонтального свайпа | Значок SpaceHop → «Настройки жестов трекпада…». |

Закрытие или сворачивание отдельного окна сохраняет обзор открытым. Если требуется диалог сохранения, обзор уступает ему место. Клик в Dock или переход в другое приложение закрывает обзор. Ручной размер и параметры жестов сохраняются между запусками. По умолчанию мгновенные горизонтальные свайпы включены, чувствительность — 75%; их можно выключить и вернуть системную обработку.

## Как это работает

`SpaceReader` загружает системную SkyLight через `dlopen`/`dlsym`: `SLSMainConnectionID`, `SLSCopyManagedDisplaySpaces`, `SLSGetActiveSpace`, `SLSCopySpacesForWindows`. Это приватные функции для чтения рабочих столов и принадлежности окон.

`SpaceSwitcher` перехватывает сочетания через Quartz event tap и посылает короткую последовательность событий Dock с недокументированными полями. После этого он проверяет фактический переход. Если его не удаётся подтвердить примерно за 0,6 секунды, утилита приостанавливает перехват. На краях списка Spaces переход наружу блокируется.

При зажатой левой кнопке новый Ctrl + ←/→ не заменяется синтетическим жестом: нажатие, повторы и отпускание проходят в macOS. Это позволяет переносить окно штатно, не вызывая паузу SpaceHop. Следующее нажатие без зажатой мыши снова обрабатывается мгновенно.

Каталог объединяет WindowServer и Accessibility; `_AXUIElementGetWindow` связывает AX-окно с его точным CGWindowID. При отсутствии AX-записи для другого Space допускаются только подходящие именованные окна с подтверждённой принадлежностью к Space. Обзор реализован панелью AppKit, снимки — ScreenCaptureKit.

Все эти вызовы выполняются локально. Собственный код SpaceHop не отправляет данные в интернет, не содержит аналитики и не сохраняет снимки на диск. Он хранит настройки в UserDefaults, а превью — только в памяти процесса. После перезапуска для свёрнутого или ещё не захваченного окна может отображаться иконка. Нижняя полоска использует уже имеющиеся снимки; окна других Spaces специально не разворачиваются для съёмки.

## Исходники и проверки

| Файл | Назначение |
| --- | --- |
| `Sources/SpaceHop.swift` | Spaces, перехват сочетаний, проверка переходов, меню и диагностические режимы. |
| `Sources/Overview.swift` | Каталог, действия над окнами, карточки, сетка и кэш снимков в памяти. |
| `Sources/OverviewSizing.swift` | Автоматический размер и ручные настройки по UUID монитора. |
| `Sources/HorizontalGesture.swift` | Распознавание горизонтального системного жеста и защита от повторных переходов. |
| `Sources/VerticalGesture.swift` | Вертикальные системные жесты обзора. |
| `Sources/GestureSettings.swift` | Окно настроек трекпада. |

```sh
./SpaceHop.app/Contents/MacOS/SpaceHop --self-test
./SpaceHop.app/Contents/MacOS/SpaceHop --diagnostics
```

Встроенные проверки покрывают границы Spaces, изоляцию сочетаний, поля синтетического жеста, каталог/сортировку, сетку/отступы, настройки отдельных мониторов и распознавание жестов. Они не заменяют нативную проверку переключения, реального трекпада и фокуса окон.

Режимы `--verify-*` предназначены для разработки: некоторые переключают рабочие столы, фокусируют окна или работают с тестовыми приложениями. Прежде чем запускать конкретный режим, прочитай его реализацию. Проверять закрытие, завершение и сворачивание следует на одноразовых окнах. Отчёты могут содержать личные заголовки/пути и не включены в репозиторий.
