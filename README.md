# macOS Toolbox

Набор небольших приложений для настройки macOS и более удобной работы с окнами и рабочими столами. Каждое приложение живёт в своей папке с исходниками и инструкцией по сборке.

| Приложение | Что делает |
| --- | --- |
| [SpaceHop](space_hop/) | Мгновенное переключение Spaces, равномерный обзор окон и переход к окнам других рабочих столов. |

## Скачать готовое приложение

[**SpaceHop 1.10.1 — скачать DMG**](https://github.com/fev0ks/macos-toolbox/releases/download/spacehop-v1.10.1/SpaceHop-1.10.1-arm64.dmg) · [ZIP](https://github.com/fev0ks/macos-toolbox/releases/download/spacehop-v1.10.1/SpaceHop-1.10.1-arm64.zip) · [Страница релиза](https://github.com/fev0ks/macos-toolbox/releases/tag/spacehop-v1.10.1)

Apple Silicon, macOS 13–15; работа проверена на 15.7.4. Открой DMG, перетащи SpaceHop в «Программы», извлеки диск и запусти приложение. При первом запуске нужны одобрение macOS для приложения без Developer ID и разрешения «Универсальный доступ»/«Запись экрана». Подробности — в [инструкции](space_hop/README.md#скачать-готовую-сборку).

## Сборка

У приложений могут различаться требования к системе и разрешения. Начни с README нужной папки. Для SpaceHop нужны Mac с Apple Silicon и Apple Command Line Tools со Swift; внешних пакетов нет.

```sh
cd space_hop
./build.sh
```

Сборка создаёт локальный `.app` и запускает встроенные проверки. Готовые приложения доступны в GitHub Releases; снимки экранов, локальные отчёты, ключи подписи и сборки в историю Git не включаются.
